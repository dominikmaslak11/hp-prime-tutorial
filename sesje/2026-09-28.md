## Jak wrócić do pracy

```powershell
cd C:\Users\dominik\Downloads\hp-prime-tutorial
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -VsCodeTests   # kompilacja + wszystkie testy + .vsix
code --install-extension tools\dist\hp-prime-ppl-1.0.0.vsix
powershell -ExecutionPolicy Bypass -File tools\notepadpp\install-notepadpp.ps1
```

Środowisko: MSYS2 UCRT64 (`C:\msys64\ucrt64\bin`): g++ 16.1, CMake 4.3, Ninja, Node 24, Qt 6.11 (nieużywane). VS Code w `%LOCALAPPDATA%\Programs\Microsoft VS Code`. Notepad++ w `C:\Program Files\Notepad++`, bez wtyczki NppExec.

Uwagi techniczne:
- `npx` w PowerShell (shim MSYS2) kończy się błędem `std::bad_weak_ptr`, dlatego `build.ps1` wywołuje `node node_modules\@vscode\vsce\vsce`.
- Skrypty `.ps1` muszą być zapisane jako UTF-8 **z BOM**, bo Windows PowerShell 5.1 inaczej psuje polskie znaki.
- Nową komendę PPL dodaje się tylko w `tools/data/commands.json`, a potem uruchamia `build.ps1`. Walidator, podpowiedzi, gramatyka, pliki Notepad++ i przewodnik AI aktualizują się same.
