# Programy

Kody źródłowe projektów z [rozdziału 24](../rozdzialy/24-projekty.md). Są gotowe do wklejenia w edytor HP Connectivity Kit albo do przepisania na kalkulatorze.

| Plik | Program | Opis |
|---|---|---|
| [QUIZ.txt](QUIZ.txt) | `QUIZ()` | quiz z tabliczki mnożenia z rekordem |
| [SITO.txt](SITO.txt) | `SITO()` | sito Eratostenesa z wizualizacją 20×20 |
| [PLOTER.txt](PLOTER.txt) | `PLOTER()` | rysownik wykresów z zoomem i przesuwaniem |
| [SNAKE.txt](SNAKE.txt) | `SNAKE()` | gra Snake |

## Jak wgrać program

**Na kalkulatorze:** [Shift][1] › (New) › nazwa (np. `SNAKE`) › usuń automatyczny szablon › przepisz kod › (Check).

**Przez HP Connectivity Kit:**
1. Podłącz kalkulator kablem USB i uruchom Connectivity Kit.
2. W drzewie kalkulatora kliknij prawym przyciskiem *Programs* › *New*, podaj nazwę.
3. Wklej zawartość pliku `.txt` w edytor i zapisz. Program zostanie przesłany na kalkulator.

Kod używa zapisu ASCII (`:=`, `<>`, `<=`, `>=`), który kalkulator rozumie. Znaki `π`, `√`, `Σ`, `θ` zostały zostawione w oryginalnej postaci. Connectivity Kit obsługuje Unicode.
